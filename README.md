# Quack-Earth

Short-term probabilistic seismic risk anticipation platform designed for edge, offline, and real-time operations.

## Repository Structure

- **`docs/`**: Project documentation, including the [API Documentation](docs/api_documentation.md).
- **`Backend/`**: Flask REST API for catalog caching, local reports, and risk estimation.
- **`model/`**: `quack_risk` Omori-style ETAS aftershock risk engine and data contracts.
- **`Frontend/`**: React + Vite application for interactive hazard maps and risk visualization.

## Documentation

Comprehensive API documentation is available in [docs/api_documentation.md](docs/api_documentation.md).
